Mini Release Platform

Un pequeño sistema funcional de entrega construido para practicar y documentar el recorrido desde el control de versiones hasta el despliegue automatizado en AWS.

Ver repositorio Volver a proyectos

Implementación actual

Simple por diseño. Funcional en la práctica.

El repositorio empaqueta un sitio estático con Docker, lo valida mediante GitHub Actions, administra los recursos de alojamiento en S3 con Terraform y despliega automáticamente las actualizaciones que llegan a la rama principal.

GitHubGitHub ActionsValidación DockerAWS S3

Qué existe hoy

  • Portfolio estático multilingüe construido con HTML y CSS.
  • Imagen Docker servida localmente con Nginx.
  • Controles de CI sobre estructura, respuesta del servicio y Terraform.
  • Sincronización automatizada hacia un sitio web en AWS S3.

Aprendizaje operativo

  • Separación entre validación y despliegue.
  • Reintentos de readiness incorporados después de diagnosticar una condición de carrera al iniciar Nginx.
  • Documentación de release, rollback y validación local.

Alcance actual

Es un entorno de aprendizaje y un proyecto de portfolio, no una plataforma interna a escala productiva. Su valor reside en el proceso funcional y su documentación.

Próximas direcciones

  • GitHub OIDC y permisos de AWS más restringidos.
  • Estado remoto de Terraform.
  • CloudFront y HTTPS.
  • Monitoreo y visibilidad operativa.
